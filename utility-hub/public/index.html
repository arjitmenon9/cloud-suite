API reference

MethodPathWhat it does

GET/:codeRedirect to the original URL, counts the click
GET/api/stats/:codeOriginal URL + click count
GET/api/digestLatest GitHub repo digest (written by stats-cron)

GET/metricsPrometheus metrics
